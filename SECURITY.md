# Security Policy (v7.0)
- **Supported Runtime:** Node.js 24 LTS (`>=22.0.0`), Python 3.11+
- **Standards Alignment:** NIST SP 800-218 (SSDF), OWASP ASVS, OWASP Top 10 for LLM Applications (2026)
- **Reporting a Vulnerability:** Email security@your-domain.example with reproduction steps; do not open public issues for unpatched vulnerabilities.
